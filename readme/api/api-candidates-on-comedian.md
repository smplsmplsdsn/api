

# コメディアン参加候補取得API

## エンドポイント

`GET /candidates_on_comedian?service=standup&comedian_id={comedian_id}`

指定したコメディアンが参加しているイベント候補のID一覧を取得する。

## リクエスト

### パラメータ

| パラメータ | 必須 | 説明 |
|---|---|---|
| `comedian_id` | 必須 | コメディアンID |

`comedian_id` は、1以上の整数として扱える文字列または整数を指定する。

## 認証・権限

- ログイン認証は不要。
- ロールによるアクセス制限はない。

## 取得条件

以下の条件をすべて満たす参加情報を取得する。

- 指定した `comedian_id` が参加していること。
- コメディアンのプロフィールが `active` であること。
- ユーザーのステータスが `active` であること。
- `standup` サービスの `comedian` ロールが `active` であること。

※ `member` ロールの状態は判定しない。

イベントや候補のステータス、開催日時による絞り込みは行わない。

## レスポンス

### 成功時

```json
{
  "success": true,
  "comedian_id": "5",
  "candidates": {
    "5": ["10", "12", "15"]
  }
}
```

- `comedian_id`：指定したコメディアンID
- `candidates`：コメディアンIDをキーとし、参加している候補IDを配列で返す。
- コメディアンIDおよび候補IDは文字列で返す。
- 参加している候補がない場合は空配列を返す。

### エラー時

| HTTPステータス | エラー | 説明 |
|---|---|---|
| 400 | `Invalid comedian id` | コメディアンIDが不正 |
| 405 | `Method not allowed` | GET以外のリクエスト |
| 500 | `Internal server error` | サーバー内部エラー |

## 補足

- 指定したコメディアンが存在しない場合や、取得条件を満たす参加情報がない場合も、正常終了として空配列を返す。
- 候補IDは、参加情報の登録順ではなく、データベースの取得結果順で返す。
- イベント候補そのものの詳細情報は返さない。
