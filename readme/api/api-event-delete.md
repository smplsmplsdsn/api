# `/event_delete?service=standup` イベント削除API

## 役割

イベントを削除する。

イベント作成者本人のみ削除できる。

イベントを削除すると、外部キー制約により関連する候補日と参加表明データも削除される。

## リクエスト

- **Method:** POST
- **Endpoint:** `/event_delete?service=standup`
- **Content-Type:** `application/json`

### リクエストボディ

```json
{
  "id": "65"
}
```

| Key | Type | Required | Description |
|---|---|---|---|
| `id` | string \| integer | 必須 | 削除対象のイベントID |

イベントIDは1以上の整数である必要がある。

## 認証・権限

セッションからログインユーザーを取得する。

- セッションにユーザーIDが存在すること
- `users` に該当ユーザーが存在すること
- イベントの `creator_public_id` とログインユーザーの `public_id` が一致すること

他のユーザーが作成したイベントは削除できない。

### ロールについて

このAPIでは以下のロール状態を確認しない。

- `member`
- `comedian`
- `venue_manager`

イベント作成時のロールが無効になっていても、イベント作成者本人であれば削除できる。

## 処理内容

1. POSTリクエストであることを確認する。
2. セッションからログインユーザーIDを取得する。
3. `users` からユーザー公開IDを取得する。
4. JSONボディを解析する。
5. イベントIDを検証する。
6. トランザクションを開始する。
7. 対象イベントを `FOR UPDATE` でロックして取得する。
8. イベントが存在することを確認する。
9. ログインユーザーがイベント作成者本人であることを確認する。
10. `standup_events` から対象イベントを削除する。
11. トランザクションを確定する。

## 関連データの削除

イベント削除時は、外部キー制約によって関連データも連鎖的に削除される。

| テーブル | 対象 | 動作 |
|---|---|---|
| `standup_events` | 対象イベント | 削除 |
| `standup_event_candidates` | 対象イベントの候補日 | `ON DELETE CASCADE` により削除 |
| `standup_event_candidate_comedians` | 削除された候補日の参加表明 | `ON DELETE CASCADE` により削除 |

イベントに確定候補日が設定されている場合も、イベント削除によって関連データが削除される。

参加表明データを個別に削除する処理は行わず、外部キー制約に任せる。

## レスポンス

### 成功

HTTP 200

```json
{
  "success": true
}
```

| Key | Type | Description |
|---|---|---|
| `success` | boolean | 処理結果 |

## エラー

エラー時は以下の形式で返す。

```json
{
  "success": false,
  "error": "エラーメッセージ"
}
```

| HTTP Status | Error | 発生条件 |
|---|---|---|
| 400 | `Invalid JSON` | JSONが不正、または配列として解釈できない |
| 400 | `Invalid event ID` | イベントIDが不正、または1以上の整数ではない |
| 401 | `Unauthorized` | セッションにユーザーIDが存在しない、またはユーザーが存在しない |
| 403 | `Permission denied` | イベント作成者本人ではない |
| 404 | `Event not found` | 削除対象のイベントが存在しない |
| 405 | `Method not allowed` | POST以外のメソッド |
| 500 | `通信エラーが発生しました` | その他の内部エラー |

内部エラーの詳細はレスポンスに含めず、サーバーログに記録する。

## トランザクション

イベントの取得・作成者確認・削除は、1つのトランザクション内で実行する。

処理中にエラーが発生した場合はロールバックし、削除を取り消す。

## 補足

- イベントの作成者本人のみ削除できる。
- イベントのステータスによる削除制限はない。
- 候補日や参加表明データは個別に削除せず、外部キー制約によって連鎖削除する。
- 削除後のイベント情報は返さない。
