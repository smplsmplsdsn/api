

# 会場別イベント候補取得API

## エンドポイント

`GET /candidates_on_venue?service=standup&venue_id={venue_id}`

指定した会場に紐づくイベント候補のID一覧を取得する。

## リクエスト

### パラメータ

| パラメータ | 必須 | 説明 |
|---|---|---|
| `venue_id` | 必須 | 会場ID |

`venue_id` は、1以上の整数として扱える文字列または整数を指定する。

## 認証・権限

- ログイン認証は不要。
- ロールによるアクセス制限はない。

## 取得条件

`standup_event_candidates.venue_id` が指定した `venue_id` と一致する候補を取得する。

- 候補IDの昇順で返す。
- イベントや候補のステータス、開催日時による絞り込みは行わない。
- 会場の存在やステータスは確認しない。

## レスポンス

### 成功時

```json
{
  "success": true,
  "venue_id": "113",
  "candidates": {
    "113": ["10", "12", "15"]
  }
}
```

- `venue_id`：指定した会場ID
- `candidates`：会場IDをキーとし、紐づく候補IDを配列で返す。
- 会場IDおよび候補IDは文字列で返す。
- 該当する候補がない場合は空配列を返す。

### エラー時

| HTTPステータス | エラー | 説明 |
|---|---|---|
| 400 | `Invalid venue id` | 会場IDが不正 |
| 405 | `Method not allowed` | GET以外のリクエスト |
| 500 | `Internal server error` | サーバー内部エラー |

## 補足

- 指定した会場が存在しない場合も、正常終了として空配列を返す。
- `venue_id` に先頭ゼロを含む数値文字列を指定した場合、数値に変換して処理するため、レスポンスでは先頭ゼロが除かれる。
- イベント候補そのものの詳細情報は返さない。
