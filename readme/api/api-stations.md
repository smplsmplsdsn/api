

# 駅情報取得API

## エンドポイント

`GET /stations?lat={latitude}&lng={longitude}&distance={distance}`

指定した緯度・経度を中心に、指定距離以内にある駅情報を取得する。

駅データは Standup Spot のデータベースとは別の駅マスタDBから取得する。

## 認証・アクセス制限

- ログイン認証は不要。
- `Referer` ヘッダーによるオリジン制限がある。
- `Referer` が存在しない場合や、許可されたオリジンと一致しない場合はアクセスできない。

## リクエスト

### パラメータ

| パラメータ | 必須 | 説明 |
|---|---|---|
| `lat` | 必須 | 検索中心の緯度 |
| `lng` | 必須 | 検索中心の経度 |
| `distance` | 必須 | 検索距離（メートル） |

### 入力条件

| パラメータ | 許容範囲 |
|---|---|
| `lat` | -90〜90 |
| `lng` | -180〜180 |
| `distance` | 0より大きく20,000,000以下 |

すべて数値として指定する。

## 取得条件

1. 指定した緯度・経度を中心に、検索距離内の駅を抽出する。
2. 同じ駅グループ（`station_g_cd`）に属する駅が複数ある場合は、中心地点に最も近い駅を代表として採用する。
3. 代表駅に紐づく路線名を集約する。
4. 距離の近い順に並べて返す。

- 駅グループの識別には `station_g_cd` を使用する。
- 駅グループ内で距離が同じ場合は、駅コード（`station_cd`）の昇順で代表駅を決定する。
- 距離はメートル単位で四捨五入して返す。
- 同じ路線名は重複して返さない。

## レスポンス

### 成功時

```json
[
  {
    "name": "駅名",
    "distance": 350,
    "lines": [
      "路線名1",
      "路線名2"
    ]
  }
]
```

| 項目 | 説明 |
|---|---|
| `name` | 駅名 |
| `distance` | 検索中心からの距離（メートル） |
| `lines` | 駅に紐づく路線名の配列 |

- 該当する駅がない場合は空配列 `[]` を返す。
- 距離は整数で返す。

## エラー時

| HTTPステータス | エラー | 説明 |
|---|---|---|
| 400 | `パラメータが不正です: {parameter}` | 必須パラメータがない、または数値ではない |
| 400 | `パラメータの範囲が不正です。` | パラメータが許容範囲外 |
| 403 | `アクセスが許可されていません。` | Refererがない、または許可されていないオリジン |
| 405 | `許可されていないリクエストです。` | GET以外のリクエスト |
| 500 | `サーバー内部でエラーが発生しました。` | サーバー内部エラー |

## 補足

- 検索距離の単位はメートル。
- 距離計算には MySQL の `ST_Distance_Sphere()` を使用する。
- 検索対象の駅は、駅グループコードが0より大きく、緯度・経度が有効な範囲にあるものに限定する。
- 検索結果は駅グループ単位でまとめるため、同じ駅グループに属する駅が複数あっても、駅情報は1件として返す。
