

# フィードバック送信API

## エンドポイント

`POST /feedback`

ユーザーから送信された意見・感想・不具合報告などをメールで送信する。

## 認証・権限

- ログイン認証は不要。
- ロールによるアクセス制限はない。

## リクエスト

### Content-Type

`application/json`

### パラメータ

| パラメータ | 型 | 必須 | 説明 |
|---|---|---|---|
| `service_key` | string | 必須 | 対象サービスの識別キー |
| `message` | string | 必須 | 送信する意見・感想・報告内容 |

### サービスキー

以下のサービスキーを指定できる。

| service_key | サービス名 |
|---|---|
| `demo` | Demo |
| `standup` | Standup Spot |
| `stations` | Station |

### リクエスト例

```json
{
  "service_key": "standup",
  "message": "サービスに関する意見・感想"
}
```

## 入力チェック

| 項目 | 条件 |
|---|---|
| HTTPメソッド | `POST` のみ受け付ける |
| リクエスト形式 | JSON形式であること |
| `service_key` | 許可されたサービスキーであること |
| `message` | 文字列であること |
| `message` の内容 | 前後の空白を除去した後、空文字でないこと |
| `message` の文字数 | 5000文字以内 |

入力チェックに失敗した場合はエラーレスポンスを返す。

## メール送信仕様

### 送信方式

- ライブラリ：PHPMailer
- SMTPサーバー：Gmail SMTP
- 接続方式：STARTTLS
- ポート：環境変数 `GMAIL_SMTP_PORT` で指定
- 文字コード：UTF-8
- メール形式：プレーンテキスト

### メール件名

`{サービス名} ご意見箱`

### メール本文

```text
ご意見箱に新しい投稿がありました。

【ご意見】
{ユーザーが入力したメッセージ}
```

### 環境設定

以下の環境変数を使用する。

| 環境変数 | 用途 |
|---|---|
| `GMAIL_SMTP_HOST` | SMTPサーバー |
| `GMAIL_SMTP_PORT` | SMTPポート |
| `GMAIL_SMTP_USERNAME` | SMTP認証ユーザー |
| `GMAIL_SMTP_PASSWORD` | SMTP認証パスワード |
| `GMAIL_SMTP_FROM` | 送信元メールアドレス |
| `GMAIL_SMTP_TO` | 送信先メールアドレス |

メール送信に必要な設定が不足している場合は送信失敗として扱う。

## レスポンス

### 成功時

HTTPステータス：`200 OK`

```json
{
  "success": true,
  "message": "ご意見を送信しました。ありがとうございます！"
}
```

### エラー時

| HTTPステータス | エラー | 説明 |
|---|---|---|
| 400 | `リクエスト形式が正しくありません。` | JSON形式ではない |
| 400 | `対象のサービスが正しくありません。` | サービスキーが不正 |
| 400 | `ご意見を入力してください。` | メッセージが空 |
| 400 | `ご意見は5000文字以内で入力してください。` | メッセージが5000文字を超えている |
| 400 | `ご意見の形式が正しくありません。` | メッセージの型が不正 |
| 405 | `許可されていないリクエストです。` | POST以外のリクエスト |
| 500 | `送信に失敗しました。時間をおいて再度お試しください。` | メール送信失敗 |

### エラーレスポンス例

```json
{
  "success": false,
  "error": "送信に失敗しました。時間をおいて再度お試しください。"
}
```

## 補足

- メール送信には共通の `sendMail()` 関数を使用する。
- メール送信に失敗した場合は、サーバー側のエラーログに記録する。
- SMTPの認証情報など、機密情報をログに出力しない。
- フィードバックの内容はデータベースには保存せず、メールで送信する。
