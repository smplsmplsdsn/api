# GET /events?service=standup

## 概要

`/init` が初期表示用データ全体を取得するのに対し、このAPIはイベント・候補日だけを再取得する。イベントの作成・更新後などに使用し、初期表示データ全体の再取得を不要にする。


イベント情報と候補日情報を取得する。

ログイン中の有効なメンバーのみ利用できる。

## リクエスト

- メソッド：`GET`
- パラメータ：なし

GET以外のリクエストにはHTTP 405を返し、`Allow: GET` ヘッダーを設定して終了する。この場合、JSONのエラーボディは返さない。

## 認証・利用条件

以下をすべて満たす必要がある。

- Standup Spot にログインしている
- `users.status` が `active`
- `member` ロールが `active`

条件を満たさない場合は `401 Unauthorized` を返す。

## 取得内容

### events

`standup_events` から全イベントを取得する。

- イベントIDの降順で取得する
- 候補日の有無やイベントのステータスによる絞り込みは行わない

取得フィールド：

| フィールド | 内容 |
|---|---|
| `id` | イベントID（文字列） |
| `creator_public_id` | 作成者の公開ID |
| `type` | イベント種別 |
| `name` | イベント名 |
| `message` | イベントメッセージ |
| `message_for_comedian` | コメディアン向けメッセージ |
| `image` | 画像パス |
| `status` | イベントステータス |
| `confirmed_candidate_id` | 確定した候補日ID（整数または `null`） |

#### message_for_comedian の取得条件

以下のいずれかを満たす場合に取得する。

- 有効なコメディアンである
- イベント作成者本人である

条件を満たさない場合は空文字を返す。

### event_candidates

`standup_event_candidates` から候補日を取得する。

取得フィールド：

| フィールド | 内容 |
|---|---|
| `id` | 候補日ID（文字列） |
| `event_id` | イベントID（文字列） |
| `venue_id` | 会場ID（文字列または `null`） |
| `open_at` | 開場日時 |
| `start_at` | 開演日時 |
| `fee` | 料金 |
| `comedian_ids` | 参加表明しているコメディアンIDの配列 |

候補日は `COALESCE(start_at, open_at)` の昇順、同じ日時の場合は候補日IDの昇順で取得する。

#### 候補日の取得条件

候補日の日時判定には、次の優先順位を使用する。

1. `start_at` が設定されている場合は `start_at`
2. `start_at` が `null` の場合は `open_at`

判定結果に応じて、以下のように取得する。

- **日時が今日以降の場合**：取得する
- **日時が過去の場合**：取得しない
- **日時が未定の場合**：イベント作成者本人であり、かつ有効なコメディアンまたは有効な会場管理者である場合のみ取得する

日時が今日の場合は、時刻に関係なく取得対象となる。

#### comedian_ids

取得対象となった候補日に対して、`standup_event_candidate_comedians` から参加表明しているコメディアンIDを取得する。

参加表明しているコメディアンの有効状態による絞り込みは行わない。

## レスポンス

```json
{
  "events": [
    {
      "id": "1",
      "creator_public_id": "作成者の公開ID",
      "type": "openmic",
      "name": "イベント名",
      "message": "イベントメッセージ",
      "message_for_comedian": "コメディアン向けメッセージ",
      "image": "",
      "status": "recruiting",
      "confirmed_candidate_id": null
    }
  ],
  "event_candidates": [
    {
      "id": "10",
      "event_id": "1",
      "venue_id": "5",
      "open_at": "2026-11-20 18:00:00",
      "start_at": "2026-11-20 19:00:00",
      "fee": "1000",
      "comedian_ids": []
    }
  ]
}
```

## エラー

| HTTPステータス | 内容 |
|---|---|
| `401` | 未ログイン、または利用条件を満たさない |

## 備考

- イベント情報は候補日の有無にかかわらず全件取得する。
- イベントの `status` による取得制限は行わない。
- 候補日の取得条件は日時とユーザーの権限によって決まる。
- イベント情報と候補日情報は、それぞれ独立した配列として返す。
