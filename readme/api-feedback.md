# フィードバック機能仕様書

## 1. 概要

ユーザーがサービスに対する意見・感想・不具合報告を送信できる機能。

送信された内容は、Gmail SMTP を利用して指定のメールアドレスに送信する。

## 2. 機能仕様

- ユーザーが入力した意見・感想・不具合報告を送信する。
- 送信先のサービスを識別するため、サービスキーを指定する。
- メール送信には PHPMailer を使用する。
- メール送信の結果を JSON 形式で返す。
- メール送信に必要な認証情報は `.env` で管理する。

## 3. API 仕様

### エンドポイント

`POST /feedback`

### リクエスト

Content-Type: `application/json`

| パラメータ | 型 | 必須 | 説明 |
|---|---|---|---|
| `service_key` | string | 必須 | 対象サービスの識別キー |
| `message` | string | 必須 | 送信する意見・感想・報告内容 |

リクエスト例：

```json
{
  "service_key": "standup",
  "message": "サービスに関する意見・感想"
}
```

## 4. 入力チェック

| 項目 | 条件 |
|---|---|
| HTTP メソッド | `POST` のみ受け付ける |
| リクエスト形式 | JSON 形式であること |
| サービスキー | 許可されたサービスキーであること |
| メッセージの型 | 文字列であること |
| メッセージの内容 | 前後の空白を除去した後、空文字でないこと |
| メッセージの文字数 | 5000 文字以内 |

入力チェックに失敗した場合は、エラーレスポンスを返す。

## 5. メール送信仕様

### 送信方式

- ライブラリ：PHPMailer
- SMTP サーバー：Gmail SMTP
- 接続方式：STARTTLS
- ポート：`.env` の `GMAIL_SMTP_PORT` で指定
- 文字コード：UTF-8
- メール形式：プレーンテキスト

### メール件名

`{サービス名} ご意見箱`

### メール本文

```text
ご意見箱に新しい投稿がありました。

【ご意見】
{ユーザーが入力したメッセージ}
```

### 環境設定

以下の設定値を `.env` で管理する。

| 環境変数 | 用途 |
|---|---|
| `GMAIL_SMTP_HOST` | SMTP サーバー |
| `GMAIL_SMTP_PORT` | SMTP ポート |
| `GMAIL_SMTP_USERNAME` | SMTP 認証ユーザー |
| `GMAIL_SMTP_PASSWORD` | SMTP 認証パスワード |
| `GMAIL_SMTP_FROM` | 送信元メールアドレス |
| `GMAIL_SMTP_TO` | 送信先メールアドレス |

認証情報を含む `.env` は Git 管理対象に含めない。

## 6. レスポンス仕様

### 成功時

HTTP ステータス：`200 OK`

```json
{
  "success": true,
  "message": "ご意見を送信しました。ありがとうございます！"
}
```

### 失敗時

HTTP ステータスとエラーメッセージを返す。

| ステータス | 条件 |
|---|---|
| `400 Bad Request` | リクエスト形式、サービスキー、入力内容が不正 |
| `405 Method Not Allowed` | POST 以外のリクエスト |
| `500 Internal Server Error` | メール送信失敗 |

レスポンス例：

```json
{
  "success": false,
  "error": "送信に失敗しました。時間をおいて再度お試しください。"
}
```

## 7. フロントエンドの処理

1. フォームからメッセージを取得する。
2. 送信前に必須入力と文字数をチェックする。
3. `POST /feedback` に JSON 形式でリクエストを送信する。
4. レスポンスの `success` を確認する。
5. 成功時は完了メッセージを表示し、フォームをリセットする。
6. 失敗時はエラーメッセージを表示する。
7. 送信中は送信ボタンを無効化し、二重送信を防止する。

## 8. エラー記録

メール送信に失敗した場合や、メール送信に必要な設定が不足している場合は、サーバー側のエラーログに記録する。

SMTP の認証情報など、機密情報をログに出力しない。
