# Googleログイン設定手順

Google ログイン（OAuth）の機能自体は無料で利用可能（クレジット機能（請求先情報）の登録不要）。

**1. Google Cloud Console へのアクセス**

   [Google Cloud Console](https://console.cloud.google.com/) にアクセスし、プロジェクトを作成（または選択）する。

**2. OAuth 同意画面の設定（※必須）**
   1. 画面左メニュー `APIとサービス` > `OAuth 同意画面` を選択
   2. 「開始」もしくは「OAuth クライアントを作成」を選択
   3. アプリケーションの種類、名前（アプリ名）、ユーザーサポートメールを入力して「次へ」
   4. 対象 「外部」（または組織内なら「内部」）を選択して「次へ」
   5. 連絡先情報（メールアドレス）を入力して「次へ」
   6. 終了（規約の同意を確認）チェックして「続行」＞「作成」<br>
   **テストユーザーの追加（※必要に応じて）**:
     プロジェクト作成者自身のアカウントでテストする場合は登録不要でログインできるが、別アカウントでテストする際に 403 エラーが発生する場合は、`OAuth 同意画面` ページ内の「テストユーザー」セクションで `+ ADD USERS` からメールアドレスを追加する。<br>※ひとつのプロジェクトにつき同意画面はひとつのみ作成可能。

**3. OAuth クライアント ID の作成**
   1. 画面左メニュー `APIとサービス` > `認証情報` を選択
   2. 上部の `+ 認証情報を作成` > `OAuth クライアント ID` を選択
   3. アプリケーションの種類: `ウェブ アプリケーション` を選択
   4. 名前: 任意の名前を入力（例: `My Web App Client`）
   5. 承認済みの JavaScript 生成元: （必要に応じて設定だが、このプロジェクトでは不要）
   6. 承認済みのリダイレクト URI: 認証完了後にリダイレクトさせる自作アプリの URL を設定<br>（例: `http://localhost:3000/api/auth/google/callback` など）
   7. 「作成」をクリック

**4. 認証情報の保存（超重要）**

   表示された **「クライアント ID」** と **「クライアント シークレット」** をコピーする。<br>
   特に**クライアント シークレット**は第三者に絶対知られないよう厳重に管理する（Git などのリポジトリにコミットしないこと）。

**5. 環境変数の設定**

   `.env` ファイルの下記箇所に取得した情報を設定する。
   ```env
   GOOGLE_CLIENT_ID=xxx
   GOOGLE_CLIENT_SECRET=xxx
   GOOGLE_REDIRECT_URI=xxx
  ```

## テストモードから公開モードへの反映手順

   1. 画面左メニュー `APIとサービス` > `OAuth 同意画面` を選択
   2. 画面左メニュー `対象` を選択
   3. 「アプリを公開」を選択し、モーダルの表示内容を確認し問題なければ「確認」を選択

   「アプリを公開」が表示されない場合は、必要項目を保存してから再度確認する。
   1. 画面左メニュー `ブランディング` を選択
   2. 必要項目を入力して「保存」
